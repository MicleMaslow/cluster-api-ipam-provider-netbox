# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report unacceptable behaviour privately to the maintainer (@MicleMaslow): open a report at https://github.com/MicleMaslow/cluster-api-ipam-provider-netbox/security/advisories/new with a title starting with "Code of Conduct", or use GitHub's [report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) feature. Reports are kept confidential.
