# Security Policy

## Reporting a vulnerability

Do not report vulnerabilities in public issues or pull requests. Open a private report at https://github.com/MicleMaslow/cluster-api-ipam-provider-netbox/security/advisories/new.

Include the provider version, the NetBox and Cluster API versions, the steps to reproduce and the impact you see, for example a token exposed, or a NetBox object changed that the provider never touches: one without its key (other than a prefix adopted with `spec.prefix`), or with the key of another instance. The maintainers confirm the report, agree on a fix and a disclosure date with the reporter, and publish a GitHub security advisory with the release that fixes it.

## Supported versions

Fixes go to the latest v0.1.x release.
