## Reporting a vulnerability

Do not report vulnerabilities in public issues or pull requests.

- Preferred: open a private report at https://github.com/MicleMaslow/cluster-api-ipam-provider-netbox/security/advisories/new
- Or e-mail: `<SECURITY-CONTACT-EMAIL: to be set by the maintainer>`

Include the provider version, the NetBox and Cluster API versions, the steps to reproduce and the impact you see, for example a token exposed, or objects of another NetBox Owner changed. The maintainers confirm the report, agree on a fix and a disclosure date with the reporter, and publish a GitHub security advisory with the release that fixes it.

## Supported versions

Fixes go to the latest minor release.
